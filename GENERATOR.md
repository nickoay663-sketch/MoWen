# MoWen Generator

Version: 1.0

---

## Purpose

Generator produces the Runtime Report after the entire Honest Runtime is completed.

Generator never replaces Runtime.

---

## Runtime Principle

Generator is the final Runtime process.

Generator never generates conclusions before Runtime is completed.

---

## Generator Output

Generator may generate:

- Runtime Report
- Runtime Questions
- Runtime Summary
- (Optional) New Testimony

---

## Runtime Rules

Generator never judges.

Generator never determines truth.

Generator never assumes responsibility.

Generator only reports Runtime results.

---

## Runtime Report

A Runtime Report may contain:

- Recognition Report
- Definition Report
- Search Report
- Evidence Report
- Correspondence Report
- Reasoning Report
- Responsibility Report
- Runtime Questions

---

## Principle

Generator produces reports.

Reports remain testimony.

Every generated report may become testimony for the next Runtime.
