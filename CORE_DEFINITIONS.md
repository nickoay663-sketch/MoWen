# MoWen Core Definitions

Version: 1.3

# 莫问核心定义 v1.3


## Layer 1

# Runtime Foundation

These concepts define the operation of Honest Runtime.

这些概念定义诚实运行。


---

## Expression

Expression is the object entering MoWen.

表达是进入莫问的对象。


MoWen analyzes expressions, not people.

莫问分析表达，不分析人。


---

## Language Environment

Language Environment is the original testimony environment of expression.

语言环境是表达原始证词环境。


Language changes.

Runtime responsibility remains the same.


语言可以变化。

Runtime 责任结构不变化。


---

## Semantic Object

Semantic Object is the unified runtime object.

统一语义对象是统一运行对象。


It preserves:

- Original expression
- Language environment
- Semantic structure
- Responsibility information


它保留：

- 原始表达
- 语言环境
- 语义结构
- 责任信息


---

## Testimony

Testimony is an expression that enters Honest Runtime after clarification.


证词是经过定义后进入诚实运行的表达。


---

## Definition

Definition is the foundation of understanding.

Without definition, reasoning cannot begin.


定义是理解基础。

没有定义，就没有推理。


---

## Concept

Concept is the meaning unit recognized by Runtime.


概念是 Runtime 识别的意义单位。


---

## Object

Object is the entity or target referred to by expression.


对象是表达指向的实体或目标。


---

## Search

Search provides supporting information required by Runtime.


检索提供运行所需的信息支持。


---

## Evidence

Evidence records whether testimony has support.


证据记录证词是否具有支持。


---

## Correspondence

Correspondence checks relationships between:

Expression

Definition

Object

Evidence


对应检查：

表达

定义

对象

证据

之间的关系。


---

## Reasoning

Reasoning checks whether conclusions follow from verified relationships.


推理检查结论是否由已验证关系产生。


---

## Responsibility

Responsibility returns expression responsibility to the testimony provider.


责任将表达责任返回给证词提供者。


---

## Reconstruction

Reconstruction creates an expression that can better bear responsibility.


重构生成更能够承担责任的表达。


---

# Layer 2

# Runtime Results


Runtime does not output judgment.

Runtime outputs verification status, questions and responsibility information.


Runtime 不输出裁决。

Runtime 输出验证状态、问题和责任信息。


---

## Honesty

Honesty is the permanent operating principle of MoWen.


诚实是莫问永久运行原则。


---

## Verification Status

Runtime results describe the current verification condition.


验证状态描述当前运行条件。


---

# Layer 3

# Civilization Concepts


Civilization is a human system built through honesty, responsibility and trust.


文明是建立在诚实、责任和信任上的人类系统。


---

# Runtime Principle


Every Runtime concept must connect to Core Definitions.


每一个 Runtime 概念必须连接核心定义。


No Runtime definition exists independently.


任何 Runtime 定义不能独立存在。
