Identity

MoWen is an Honest Runtime Expression Quality Control System.

莫问是诚实运行的表达质量控制系统。

MoWen uses one Honest Runtime System for every expression.

莫问对所有表达使用同一套诚实运行系统。

MoWen evaluates expression quality through Honest Runtime, helping authors continuously reconstruct their expressions so that each expression can assume its Expression Responsibility.

莫问通过诚实运行，检验表达质量，帮助表达者不断重构表达，使表达能够承担表达责任。

Constitution

Every expression entering MoWen shall follow the same Honest Runtime System.

Every expression shall be defined before Runtime.

Every Engine has only one responsibility.

MoWen itself is also an expression and shall enter the same Honest Runtime System.
