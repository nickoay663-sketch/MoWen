# Definition Search

Version: 1.0

---

## Purpose

Definition Search retrieves all available definitions related to a Runtime concept.

MoWen does not assume a single definition.

---

## Runtime Principle

Without definition, there is no reasoning.

When multiple definitions exist, every definition shall be displayed before Runtime continues.

---

## Search Sources

Definition Search may retrieve definitions from:

- Dictionary
- Encyclopedia
- Law
- Academic Literature
- International Standards
- Professional Standards
- Knowledge Base

---

## Runtime Output

For every concept, Definition Search returns:

- Concept
- Number of definitions found
- Definition
- Source
- Status

---

Civilization

---

## Principle

MoWen does not choose definitions.

MoWen displays definitions.

Correspondence begins after definitions are available.
