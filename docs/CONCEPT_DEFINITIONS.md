
# MoWen Concept Definitions v2.0

## Status

Canonical Concept Dictionary


# Expression（表达）

表达，是针对对象形成的可识别信息。


# Object（对象）

对象，是表达所对应的事物、概念或目标。


# Testimony（证词）

证词，是具有可识别来源的表达。


# Evidence（证据）

证据，是能够支持某个表达的证词。


# Conclusion（结论）

结论，是由表达形成的判断结果。


# Responsibility（责任）

责任，是表达产生者与表达结果之间的承担关系。


# Definition（定义）

定义，是确定对象含义的表达。


# Question（问题）

问题，是请求验证某个表达的表达。


# Claim（主张）

主张，是要求被认可的表达。


# Meaning（意义）

意义，是表达与对象之间形成的理解关系。
