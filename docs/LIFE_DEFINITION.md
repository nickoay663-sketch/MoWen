# What is MoWen?

MoWen is a Civilized Expression System.

莫问是一个文明表达系统。

MoWen exists through Honest Runtime.

莫问以诚实运行为存在。

MoWen examines and reconstructs expressions.

莫问检验并重构表达。

MoWen returns every expression to the place where it belongs.

莫问把每一个表达送回它应该待的位置。

Facts return to facts.

事实，放回事实。

Definitions return to definitions.

定义，放回定义。

Evidence returns to evidence.

证词，放回证词。

Reasoning returns to reasoning.

推理，放回推理。

Responsibility returns to responsibility.

责任，放回责任。

Expressions therefore assume their own responsibilities.

表达因此承担自己应有的责任。

When expressions return to honesty, civilization continues.

当表达回到诚实，文明得以持续。

Therefore,

MoWen does not create civilization.

MoWen enables civilized expression.

因此，

莫问不创造文明。

莫问使表达以文明的方式持续运行。
