Semantic Object v1.0

莫问统一语义对象 v1.0

Purpose

Semantic Object is the unified runtime object of MoWen.

Every expression entering MoWen shall first be converted into one Semantic Object.

统一语义对象是莫问的统一运行对象。

所有表达进入莫问之前，必须先转换为统一语义对象。

Principle

Natural language is not the runtime object.

Semantic Object is the runtime object.

自然语言不是运行对象。

统一语义对象才是运行对象。

Independence

Different natural languages may generate the same Semantic Object.

One Semantic Object may also be expressed by different languages.

不同语言可以对应同一个统一语义对象。

同一个统一语义对象也可以使用不同语言表达。

Responsibility

Every Semantic Object shall inherit the responsibility of the original expression.

统一语义对象必须继承原始表达的责任。

Semantic conversion shall never remove responsibility.

语义转换不得消除责任。

Runtime

All Runtime Systems operate on Semantic Objects.

No Runtime directly processes natural language.

所有运行系统处理统一语义对象。

任何运行系统不得直接处理自然语言。
