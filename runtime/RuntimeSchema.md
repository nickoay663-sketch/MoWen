# Semantic Object


Every expression entering Honest Runtime shall become one Semantic Object.


统一语义对象：

Contains:

- Original Content
- Language
- Language Environment
- Expression Type
- Subject
- Object
- Concept
- Definition
- Context
- Evidence State
- Responsibility
- Runtime Status


---

# Runtime Result


Every Runtime execution returns:


Runtime Result:

- Semantic Object
- Runtime Status
- Evidence Status
- Questions
- Suggestions
- Responsibility Information
- Reconstructed Expression


---

# Schema Principle


Natural language is the input environment.

Semantic Object is the runtime object.

Honest Runtime is the execution system.


自然语言是输入环境。

统一语义对象是运行对象。

诚实运行是执行系统。


---

# Responsibility Rule


Every transformation must preserve:

- Original expression
- Language environment
- Responsibility information


任何转换必须保留：

- 原始表达
- 语言环境
- 责任信息


---

# Core Structure


One Expression.

One Semantic Object.

One Honest Runtime.

One Responsibility Chain.


一个表达。

一个统一语义对象。

一个诚实运行系统。

一条责任链。
