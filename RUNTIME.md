
Runtime

MoWen uses one Honest Runtime.

莫问使用同一套诚实运行。

---

Entry Principle

Every expression enters MoWen through Definition.

Without Definition, Runtime cannot begin.

每一个表达进入莫问前，必须经过定义。

没有定义，运行无法开始。

---

Expression and Testimony

Expression is the object entering MoWen.

Testimony is an expression that has passed Definition and can enter Honest Runtime.

表达，是进入莫问的对象。

证词，是经过定义后，可以进入诚实运行的表达。

---

Honest Runtime

MoWen uses one Honest Runtime for every expression.

MoWen itself also becomes an expression and enters the same Honest Runtime.

An Honest Runtime is one complete execution of the Honest Runtime.

莫问对所有表达使用同一套诚实运行。

莫问自身也作为表达，进入同一套诚实运行。

一次诚实运行，是诚实运行的一次完整运行。

Runtime Principles

Every expression requires Definition before Runtime.

Every Testimony follows the same Honest Runtime.

Search supports the entire Runtime.

Each Engine has only one responsibility.

Every Runtime produces a reconstructed expression that may become new testimony.

每一个表达，必须先定义，再运行。

每一个证词，接受同一套诚实运行。

检索贯穿整个运行。

每一个模块，只承担一个职责。

每一次运行，产生重构后的表达；重构后的表达可以成为新的证词。

---

Engine Principle

Each Engine completes only its own responsibility.

Each Engine may invoke Search when required.

No Engine replaces another Engine.

每一个模块，只完成自己的职责。

每一个模块，可以在需要时调用检索。

任何模块，不替代其他模块。

---

Runtime Result

MoWen does not replace human judgment.

MoWen examines Expression Responsibility.

Honest Runtime reconstructs the expression into one that can better bear responsibility.

莫问不代替人的判断。

莫问检查表达责任。

诚实运行将表达重构为更能够承担责任的表达。
