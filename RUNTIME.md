# MoWen Runtime v1.2

## Runtime

MoWen uses one Honest Runtime.

All expressions enter the same responsibility structure.

莫问使用同一套诚实运行。

所有表达进入同一套责任运行结构。


## Entry Principle

Every expression enters MoWen through Language Runtime.

Language Runtime establishes the original testimony environment.

Without Definition, Runtime cannot continue.

每一个表达进入莫问前，首先经过语言运行系统。

语言运行系统建立原始证词环境。

没有定义，运行无法继续。


## Expression and Testimony

Expression enters MoWen Runtime.

Testimony enters Honest Runtime after recognition and definition processing.

表达进入莫问运行系统。

证词经过识别和定义处理后进入诚实运行。


## Honest Runtime

MoWen uses one Honest Runtime for every expression.

MoWen itself also becomes an expression and enters the same Honest Runtime.

An Honest Runtime is one complete execution of responsibility analysis.

莫问对所有表达使用同一套诚实运行。

莫问自身也作为表达进入同一套诚实运行。

一次诚实运行，是一次完整的责任分析过程。
