Architecture

MoWen Architecture

莫问架构

Overview

MoWen is an Expression Quality Control System.

Every expression enters the same Honest Runtime.

莫问是表达质量控制系统。

每一个表达都进入同一套诚实运行。

---

Architecture Principle

Every expression enters MoWen through Definition.

After Definition, the expression becomes Testimony.

Testimony enters Honest Runtime.

每一个表达进入莫问前，必须经过定义。

经过定义后的表达成为证词。

证词进入诚实运行。

---

Honest Runtime

Honest Runtime consists of Runtime Engines.

诚实运行由运行模块组成。

---

Runtime Engines

Recognition Engine

Recognizes testimony, objects and concepts.

识别证词、对象与概念。

---

Definition Engine

Provides clear and consistent definitions.

提供明确且一致的定义。

---

Search Engine

Provides information support throughout Runtime.

检索为整个运行提供信息支持。

---

Evidence Engine

Records evidence related to testimony.

记录与证词相关的证据。

---

Correspondence Engine

Checks correspondence between testimony, definition, object and evidence.

检验证词、定义、对象和证据之间的对应。

---

Reasoning Engine

Checks whether conclusions follow from previous Runtime.

检验结论是否能够由前面的运行推出。

---

Responsibility Engine

Checks expression responsibility.

检查表达责任。

---

Reconstruction Engine

Reconstructs the expression into one that can better bear responsibility.

将表达重构为更能够承担责任的表达。

---

Runtime Result

Honest Runtime produces a reconstructed expression.

The reconstructed expression may become new testimony.

诚实运行生成重构后的表达。

重构后的表达可以作为新的证词进入下一次诚实运行。

---

Architecture Rules

Each Engine has only one responsibility.

Each Engine may invoke Search when required.

No Engine replaces another Engine.

每一个模块只有一个职责。

任何模块可以在需要时调用检索。

任何模块不替代其他模块。

---

Self Application

MoWen architecture itself follows the same Honest Runtime.

MoWen documents, modules and expressions can all enter the same Runtime.

莫问架构自身也遵循同一套诚实运行。

莫问的文档、模块和表达，都可以进入同一套运行。

一个概念。
