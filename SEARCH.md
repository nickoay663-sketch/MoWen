# MoWen Search

Version: 2.0

---

## Principle

Search is not a Runtime stage.

Search is a Runtime capability.

Search runs throughout the entire Honest Runtime.

---

## Runtime

Recognition
    ↕ Search

Definition
    ↕ Search

Evidence
    ↕ Search

Correspondence
    ↕ Search

Reasoning
    ↕ Search

Responsibility
    ↕ Search

Generator
    ↕ Search

---

## Search Responsibilities

Search retrieves:

- Objects
- Definitions
- Evidence
- Knowledge
- Laws
- Academic Papers
- Historical Records
- Standards
- Previous Runtime Reports

Search never generates conclusions.

---

## Principle

Every Runtime stage may request Search.

Search serves Runtime.

Search never replaces Runtime.
